# Planifest - Event Management Application

Welcome to **Planifest**!  
Planifest is a modern web application that allows users to **create, join, and manage events**, receive information about them, and interact with other participants. A **user account system** and **moderation tools** are included to ensure smooth management.

## 🌐 Overview
Check out the website here: https://planifest.amaurymulcey.fr

Planifest enables users to:  
- **Create events** with details like date, location, and description  
- **Join events** and stay informed about updates
- **Manage their account** and personal information  
- **Moderate content and participants** if they have the proper permissions .

## ⚡ Technologies Used

**Frontend**  
- Vue 3  
- TypeScript  
- Vue Router  
- Pinia
- TailwindCSS
- HTML5 & CSS3

**Backend**  
- Symfony 6  
- API Platform for REST endpoints  
- Doctrine ORM for database management  
- LexikJWTAuthenticationBundle for authentication  

**Development Tools**  
- Git & GitHub

## 🛠 Features

**User Accounts**  
- Sign up / log in  
- Password hashing and JWT authentication  
- Profile management  

**Events**  
- Create, edit, delete events  
- Join or leave events

**Moderation**  
- Admin and moderator roles  
- User reporting system  

**Frontend UI**  
- Fully responsive  
- Smooth navigation and interactions  

## 🚀 Installation & Development

### Installation
```bash
# Clone the repository
git clone https://github.com/AmauRizz/planifest.git
cd planifest


# Install PHP dependencies
composer install

# Start Symfony server
symfony server:start

cd

# Install Node dependencies
npm install

# Start frontend dev server (Vue)
npm run dev
```
